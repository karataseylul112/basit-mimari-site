# Basit Mimarlık Web Sitesi

Bu proje, HTML ve CSS temellerini pekiştirmek ve şık bir arayüz tasarımı ortaya çıkarmak amacıyla hazırladığım statik bir mimarlık web sitesidir.

## Özellikler

* Minimalist renk paleti ve tipografi seçimi
* Sabit ve kullanışlı üst menü (navbar) yapısı
* Butonlar ve menü elemanları için CSS geçiş efektleri
* Karartılmış şık banner arka plan alanı

## Kullanılan Teknolojiler

* **HTML5:** Sayfanın temel iskeleti
* **CSS3:** Tasarım, konumlandırma ve efektler
